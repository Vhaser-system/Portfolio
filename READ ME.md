# Julian Visser — Writing Portfolio

Source for [julianvisser-portfolio.netlify.app](https://julianvisser-portfolio.netlify.app) — a
single-page portfolio holding scripts, short fiction, spec work, case studies and research samples.
Static HTML with pre-compiled Tailwind CSS. Netlify deploys from this repository.

## Structure

```
/
├── index.html            # the whole site — one page, no framework
├── styles.css            # GENERATED by Tailwind; do not edit by hand
├── input.css             # Tailwind entry point (@tailwind directives)
├── tailwind.config.js    # theme: brand colours, Inter/Merriweather
├── fonts/                # self-hosted Inter + Merriweather woff2 + fonts.css
├── documents/            # every PDF and video the on-page viewer opens
└── images/               # profile.jpg, favicon.png
```

**All viewer documents load from `documents/`**, including the AI-augmented research PDFs. If a local
working copy also has a `Research output/` folder, it is a leftover — `index.html` does not reference
it, and duplicating files there will drift out of sync with what the site actually serves.

## Editing the site

`index.html` is the only file to edit for content.

**If you add or change any Tailwind class, regenerate the stylesheet:**

```bash
npx tailwindcss@3 -c tailwind.config.js -i input.css -o styles.css --minify
```

Commit the regenerated `styles.css`. Skipping this step means new classes silently have no styling.

The site previously loaded Tailwind from `cdn.tailwindcss.com` — the v3-era Play CDN, which Tailwind's
documentation describes as "designed for development purposes only, and is not intended for
production." (That endpoint is now legacy; Tailwind v4 moved the Play CDN to
`cdn.jsdelivr.net/npm/@tailwindcss/browser@4`. This site was on the old URL.) It shipped roughly
400 KB of JavaScript and compiled the CSS in the browser on every visit. The pre-compiled stylesheet
is about 26 KB, roughly 5 KB gzipped.

## Fonts

Inter and Merriweather are **self-hosted** in `fonts/`. Nothing is requested from
`fonts.googleapis.com` or `fonts.gstatic.com` at page load, so no visitor IP address is sent to
Google. `fonts/fonts.css` keeps the original `unicode-range` blocks, so browsers still download only
the character subsets they actually need.

To change weights: re-fetch the Google Fonts CSS, download the referenced `.woff2` files into
`fonts/`, and rewrite the `src:` URLs to local paths.

Both families are licensed under the **SIL Open Font License 1.1**, which requires the copyright
notice and licence text to travel with any redistributed copy. Since this repository is public and
ships the `.woff2` files directly, `fonts/Inter-OFL.txt` and `fonts/Merriweather-OFL.txt` must stay
alongside them.

## Adding a document

1. Put the file in `documents/`.
2. Add a card in `index.html` with a button calling
  `openDocument('Title shown in the viewer', 'documents/Your%20File.pdf')`.
3. URL-encode spaces as `%20`.
4. Keep the viewer title consistent with the card heading above it.

## Remaining third-party dependency

`unpkg.com/lucide@latest` still loads the icon library at runtime, and `@latest` is unpinned — the
version can change without warning. Pin it to a specific version, or vendor the icons locally.
